Polish

Raw transcript to clean text.

One dictation. Four polishing modes.
Click a mode to see what the same words become.

App-aware

Different apps, different polish.

A casual Slack message and a board update email shouldn't sound the same. Auris ships with six app-aware mode presets.
Mode · 01

Default.

The global slider settings apply. Most apps you don't override end up here.

Mode · 02

Formal.

Formality and assertiveness pushed up. Email clients, document editors, board updates.

Mode · 03

Casual.

Formality pushed down. Chat apps: Slack, Discord, Messages.

Mode · 04

Minimal.

Only fixes typos and grammar. Leaves your phrasing alone.

Mode · 05

Code.

Preserves quotes and brackets. Doesn't auto-capitalize identifiers. Terminals and editors.

Mode · 06

Email.

Full sentences, signature-ready phrasing. Mail, Outlook, Gmail.

Assign any mode to any app. Override with custom rules for anything specific.

Recall

Past dictations, measured.

No cloud, no telemetry.
Your history is a local file you can search, edit, and re-polish.

History · Inline editing · Range filters · Top-apps chart · Backend latency. Every dictation goes to history.jsonl in your Auris folder. Grep it, edit it, delete the file to wipe history.

Workspace

Open the folder. Read the files.

Memos are real .md files. History is one .jsonl. Dictionary is plain .json. Auris owns nothing. Open them in any editor, sync them via Dropbox or git, version them however you like.
