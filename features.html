Polish · 002

Raw transcript to clean text.

One dictation. Four polishing modes. Click a mode to see what the same words become.
You said so basically what i'm trying to say is we should probably ship by friday um yeah and like loop in whoever needs to be ready by thursday
Auris polished We should aim to ship by Friday. Please coordinate with the team to ensure all dependencies are resolved by EOD Thursday.
Plus: choice of model (Anthropic, OpenAI, Groq, Ollama, LM Studio), seven cleanup toggles, five output formats, role-break guard, polish bench for testing settings on pasted text.
